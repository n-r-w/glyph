# Terms

- Browser sign-in: Authorization completed through a browser redirect to a listener on the Glyph computer.
- Device-code sign-in: Authorization completed by entering a one-time code on the provider's website while Glyph polls for approval.
- User code: The one-time value entered on the provider's verification page.
- Device authorization ID: The provider's identifier used by Glyph to poll one pending device authorization.
