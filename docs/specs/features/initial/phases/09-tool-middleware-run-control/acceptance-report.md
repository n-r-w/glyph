## Delivered scope

All U0-U15 delivery units and the U9.1/U14.1 test-harness corrections are committed. The [requirements](prd.md#requirements), [critical scenarios](prd.md#critical-scenarios) and [technical solution](solution.md#proposed-solution) define the delivered contracts.

- Host applies ordered tool policies, preserves complete failure text and projects tool-error categories through finalized results, history and model requests.
- Extensions can replace tools, inspect available tool registrations and change the active tool set for subsequent model requests.
- Agent Core executes consecutive concurrent calls together, enforces serial barriers and records results in source-call order.
- Agent Core owns `steer`, `followUp` and `nextTurn` delivery, queue modes, undelivered-message return and the batch-wide `terminate` decision.
- Extensions can request cancellation of the active run. Core retains every accepted abort source, preserves independent failure precedence and retains pending `nextTurn` messages.
- Programmatic Control clients receive startup issues, including conflicting tool replacements.

The pre-phase and delivered contents of every `go.mod` and `go.sum` file are identical.
